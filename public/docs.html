Introducción

La API de RutaFleet TMS permite integrar tu ERP o e-commerce con la operación logística de última milla: crear pedidos, optimizar rutas (incluyendo madre nodriza y recolecciones), despachar vehículos, seguir su posición GPS y recibir la prueba de entrega.

Base URL: http://localhost:3000/api/v1. Todas las respuestas usan JSON con la forma { "data": ... } y los errores { "error": "mensaje" }.

Autenticación

Esta réplica de demostración no exige credenciales. En un despliegue real se usaría un encabezado Authorization: Bearer <api_key> por empresa.

Optimización de rutas

El motor VRP asigna pedidos pendientes a los vehículos indicados usando barrido angular, vecino más cercano y mejora 2-opt, validando capacidad en kg y m³. Soporta dos modos:

  • Clásico: cada vehículo sale del centro de distribución.
  • Madre nodriza: un vehículo mayor lleva la carga a puntos de transbordo y los vehículos satélite reparten cada zona desde allí. Ideal para zonas alejadas del depósito.

Las recolecciones se intercalan en la ruta validando que la carga a bordo nunca supere la capacidad del vehículo; si no hay espacio, la recolección se pospone a un punto posterior de la ruta.

Prueba de entrega (POD)

Registra la evidencia de entrega o recolección de un pedido. El simulador la genera automáticamente al completar cada parada; también puede registrarse de forma manual.

POST/orders/{id}/pod
POST /api/v1/orders/ORD-1005/pod
{
  "receiver": "María Pérez",
  "method": "firma_digital",    // firma_digital | foto | codigo
  "notes": "Recepción conforme en bodega",
  "failed": false               // true marca el pedido como no_entregado
}

Webhooks

Suscribe una URL para recibir un POST JSON cuando ocurra un evento. El encabezado X-RutaFleet-Event indica el tipo.

GET/webhooks
POST/webhooks
DELETE/webhooks/{id}
EventoSe emite cuando…
order.createdSe crean pedidos por API
order.status_changedCambia el estado de un pedido (incluye POD)
route.plannedEl optimizador genera rutas
route.startedUna ruta es despachada
route.transfer_completedLa nodriza completa un transbordo
route.completedUna ruta finaliza
